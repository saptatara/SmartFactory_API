Calculation Methodology
LMTD (Log Mean Temperature Difference) Method:

Heat Duty Calculation:

Q = m_hot × Cp × (T1_in - T1_out)

Q = m_cold × Cp × (T2_out - T2_in)

LMTD Calculation:

ΔT1 = T1_in - T2_out

ΔT2 = T1_out - T2_in

LMTD = (ΔT1 - ΔT2) / ln(ΔT1/ΔT2)

Fouling Factor:

Rf = (1/U_actual - 1/U_clean)

Where: Cp = 4186 J/kg·K (water), U_actual = Q / (A × LMTD)

Correct Fouling Factor Calculation:

Actual Conditions:

Q_actual = m × Cp × ΔT_actual

LMTD_actual = f(T1_in, T1_out, T2_in, T2_out)

U_actual = Q_actual / (A × LMTD_actual)

Fouling Factor:

Rf = 1/U_actual - 1/U_clean


Performance Ratio:

η = U_actual / U_clean × 100%

This method compares ACTUAL operating conditions against DESIGN/clean conditions to calculate the true fouling factor.
